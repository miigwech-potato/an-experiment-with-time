# synchronicities

One row per coincidence in `register.csv`, recorded to the minute.

The last column is the one that does the work: `base_rate_estimate`, your own
answer to how often that could happen anyway. A register without it collects
everything; a register with it collects what stands out from everything.

Columns: id, date, local_time, what_happened, what_it_coincided_with,
how_i_noticed, base_rate_estimate, notes.
